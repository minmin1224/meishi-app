# 名刺管理

スマホで名刺を撮影するだけでOCRが氏名・会社名・連絡先を自動入力し、50音順・氏名順・会社名順に整理できるブラウザアプリです。

- ランディングページ: `index.html`
- アプリ本体: `app/index.html`

インストール不要、ブラウザだけで動作します。データは端末のlocalStorageに保存され、サーバーには送信されません。文字認識(OCR)は外部ライブラリを読み込むため、初回利用時のみインターネット接続が必要です。

PWA(Progressive Web App)対応で、スマホのホーム画面に追加するとアプリのように起動できます(詳細はランディングページの「ホーム画面への追加方法」を参照)。
